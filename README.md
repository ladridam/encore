# Encore

A modern community-centered platform designed to connect retired professionals with meaningful mentorship and flexible local skill-sharing opportunities.

![Encore Preview](./assets/previews/hero.png)

---

## Overview

Encore is a conceptual digital platform created during a Design-o-thon to address the growing disconnect between retired professionals and communities that can benefit from their experience.

Many retired teachers, engineers, clerical professionals, and skilled individuals possess decades of expertise but often lack structured opportunities to continue contributing meaningfully after retirement.

Encore bridges this gap by creating a localized ecosystem for:
- mentorship,
- part-time knowledge sharing,
- flexible engagement,
- and community-driven collaboration.

The project focuses on simplicity, accessibility, trust, and human connection.

---

## Problem Statement

Design a platform that connects retired professionals with local mentorship and part-time skill-sharing opportunities.

Many retired teachers, engineers, and clerical professionals possess valuable expertise but lack structured opportunities to contribute. A digital platform can help them engage in meaningful, flexible, and local mentoring roles.

### Expected Outcomes
- Profile-based skill listing for retired professionals
- Matching system for mentorship and part-time opportunities
- Local opportunity discovery based on expertise and location
- Community feedback and engagement tracking

---

## Key Features

### Skill-Based Profiles
Retired professionals can create profiles showcasing:
- expertise,
- years of experience,
- preferred mentorship categories,
- and availability.

### Local Opportunity Discovery
Users can discover mentorship and part-time opportunities nearby based on:
- location,
- skillset,
- and community needs.

### Mentorship Matching
The platform proposes relevant mentorship connections between:
- learners,
- organizations,
- and experienced professionals.

### Community Trust System
Community reviews and engagement metrics help establish:
- credibility,
- trust,
- and consistent contribution recognition.

### Accessible Interface
The platform prioritizes:
- simple navigation,
- readable typography,
- high contrast layouts,
- and low cognitive load for elderly users.

## Installation

Clone the repository:

```bash
git clone https://github.com/ladridam/encore.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Accessibility Considerations

The interface was designed while considering elderly users and accessibility needs through:
- larger readable typography,
- clear visual hierarchy,
- minimal navigation complexity,
- responsive layouts,
- and accessible spacing systems.
