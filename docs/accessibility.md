# Accessibility Considerations

Encore was designed with accessibility and inclusivity as core priorities.

---

## Typography

- Larger readable font sizes
- Clear heading hierarchy
- Balanced spacing between content sections

---

## Visual Design

- High contrast interface
- Minimal visual clutter
- Calm and readable layout system

---

## Navigation

- Reduced navigation complexity
- Predictable interaction patterns
- Simple information flow

---

## Responsive Design

The platform was designed to work across:
- desktops,
- tablets,
- and mobile devices.

---

## Cognitive Accessibility

The interface avoids:
- overwhelming animations,
- excessive interaction layers,
- and complicated workflows.

The goal was to create a comfortable experience for elderly users.
